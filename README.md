# Habib Download Manager

A Chrome/Edge browser extension starter for listing and controlling direct browser downloads.

## Load locally

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this repository folder.

## Features

- Lists recent browser downloads
- Shows download progress
- Pause, resume, and cancel controls
- Uses Chrome's Downloads API

## Limitations

This extension can manage downloads Chrome or Edge already permits. It does not bypass DRM, capture protected streaming media, or download content without the user's permission.
